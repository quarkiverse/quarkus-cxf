== Dummy logging extension no longer published

`io.quarkiverse.cxf:quarkus-cxf-rt-features-logging` was deprecated since {quarkus-cxf-project-name} 2.7.0,
when all its functionality including configuration properties moved to `io.quarkiverse.cxf:quarkus-cxf`.
To keep backwards compatibility, a dummy `io.quarkiverse.cxf:quarkus-cxf-rt-features-logging` artifact still existed up to {quarkus-cxf-project-name} 3.40.* doing nothing else, but outputting a warning.

Since {quarkus-cxf-project-name} 4.0.0, `io.quarkiverse.cxf:quarkus-cxf-rt-features-logging` is no longer published. You can simply remove the dependency from your projects, as all its functionality has moved to `io.quarkiverse.cxf:quarkus-cxf`
