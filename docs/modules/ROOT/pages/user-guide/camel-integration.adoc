= Camel integration

Connect your SOAP services and clients to other systems through Apache Camel routes: {link-camel-quarkus-docs-index}[Camel Quarkus] supports CXF since its version 2.12.0, and its implementation is based on {quarkus-cxf-project-name}, so all functionality available in {quarkus-cxf-project-name} is also available in Camel Quarkus.

Refer to {link-camel-quarkus-docs-cxf-soap}[Camel Quarkus CXF SOAP] extension documentation for further details.
