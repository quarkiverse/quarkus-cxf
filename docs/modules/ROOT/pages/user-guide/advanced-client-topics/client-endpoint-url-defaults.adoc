[[client-endpoint-url-defaults]]
= `client-endpoint-url` defaults

If you omit the `client-endpoint-url` property in `application.properties`,
the CXF Quarkus extension will assume that the service is published at `\http://localhost:8080/\{service-path}`,
where `\{service-path}` is derived from

* Configuration property `xref:reference/extensions/quarkus-cxf.adoc#quarkus-cxf_quarkus-cxf-path[quarkus.cxf.path]` and the
* SEI’s class name in lower case

Given `quarkus.cxf.path = /services` (default), the default effective `client-endpoint-url` of the `CalculatorService` would be
`\http://localhost:8080/services/org.jboss.eap.quickstarts.wscalculator.calculator.calculatorservice`.
