= Contributor guide


[[prerequisites-contribute]]
== Prerequisites

* `git`
* GraalVM with `native-image` command installed and `GRAALVM_HOME` environment variable set, see
  {link-quarkus-docs-base}/building-native-image[Building a native executable] section of the Quarkus
  documentation.
* If your are on Linux, `docker` is sufficient for the native mode too. Use `-Pnative,docker` instead of `-Pnative`
  if you choose this option.
* Java 17
* Maven (`mvn`), Maven Daemon (`mvnd` for fast builds), or Maven Wrapper (`mvnw`)

[[how-to-build]]
== How to build

Checkout the code

[source,shell]
----
$ git clone https://github.com/quarkiverse/quarkus-cxf.git -o upstream
$ cd quarkus-cxf
----

A fast build without tests and various checks:

[source,shell]
----
$ mvn clean install -DskipTests -Dquarkus.build.skip
----

A build with integration tests in the JVM mode only:

[source,shell]
----
$ mvn clean install
----

A build with integration tests in both the JVM mode and the native mode:

[source,shell]
----
$ mvn clean install -Pnative
----

=== Build on a FIPS-enabled machine

[WARNING]
====
Remove this section once OpenJDK on RHEL fixes the underlying problem - see https://github.com/quarkiverse/quarkus-cxf/issues/2397
====

[source,shell]
----
$ mvn clean install -Dfips
----

With JDK 25+, also limit the TLS named groups of the Maven JVM.
In FIPS mode, Red Hat JDK 25 offers the hybrid `X25519MLKEM768` group first by default, and the SunPKCS11 FIPS provider cannot compute it.

. Print the default named groups of your JDK:
+
[source,shell]
----
$ echo 'String.join(",", javax.net.ssl.SSLContext.getDefault().getDefaultSSLParameters().getNamedGroups())' | jshell -q
----
+
On RHEL in FIPS mode with JDK 25, it prints something like:
+
----
X25519MLKEM768,secp256r1,secp384r1,secp521r1,ffdhe2048,ffdhe3072,ffdhe4096,ffdhe6144,ffdhe8192
----

. Remove `X25519MLKEM768` from the list and pass the rest to Maven:
+
[source,shell]
----
$ export MAVEN_OPTS="$MAVEN_OPTS -Djdk.tls.namedGroups=secp256r1,secp384r1,secp521r1,ffdhe2048,ffdhe3072,ffdhe4096,ffdhe6144,ffdhe8192"
$ mvn clean install -Dfips
----

`MAVEN_OPTS` covers Maven itself (artifact downloads). On JDK 25+, `-Dfips` covers the test JVMs and the native image builder.
With JDK 21 the default list has no ML-KEM group, so `MAVEN_OPTS` needs no change.
